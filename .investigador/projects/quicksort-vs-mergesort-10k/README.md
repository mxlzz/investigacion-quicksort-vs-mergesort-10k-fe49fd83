# Investigación: quicksort-vs-mergesort-10k

Investigación comparativa entre QuickSort y MergeSort para ordenar 10.000 números enteros, ventajas, limitaciones y condiciones de preferencia.

## Avance confirmado

Se completó la investigación comparativa entre QuickSort y MergeSort para N=10.000 enteros. Se realizó búsqueda bibliográfica en Crossref, formulación de hipótesis, diseño experimental y ejecución remota verificada en GitHub Actions (Node.js 24). Los resultados experimentales confirmaron que QuickSort supera a MergeSort tanto en tiempo de ejecución (0.6993 ms vs 3.9659 ms) como en asignación de memoria en el heap (36.57 KB vs 253.08 KB) bajo las condiciones probadas.
